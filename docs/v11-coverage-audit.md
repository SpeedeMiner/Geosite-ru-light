## Отсечённый ложный кандидат

`stream.kick.com` обнаружился среди новых RU правил после импорта положительных источников.
Проверка показала, что это видеохост международного стримингового сервиса Kick, а не инфраструктура РФ.
В Go-фильтре добавлено узкое исключение для `RU` и регрессионный тест; BLOCK и другие категории не менялись.

## Механизм расширения и критерии безопасности

- Напрямую обходится дерево `include:` корня `category-ru` и дополнительные подтверждённые категории v2fly.
- Не преобразуются `full:`, `regexp:`, `keyword:` и строки с атрибутами в широкие suffix-правила.
- Корневые компактные TLD проходят стандартную дедупликацию и pruning.
- `tools/geosite-delta` декодирует оба protobuf DAT и сравнивает **семантическое покрытие** (включая предков RootDomain), а не простое количество строк.
- Потеря хотя бы одного RU правила, ранее покрываемого релизом, делает PR CI красным.
- Для PR отключены публикация GitHub Release и принудительный push в `release`.

## Не завершено / требуется перед merge

1. Подтвердить актуальное владение спорными техническими доменами, в том числе `ksn-crypto-info.com`.
2. Проверить, что шесть снятых блокировок соответствуют желаемой политике `geosite:block`.
3. Проверить новые сторонние кандидаты вне компактных корней по источнику, назначению, DNS и риску международного CDN **до** включения; массово не импортировать `external-candidates.json`.
4. После проверки перевести PR из Draft в Ready for review; `main`, `release`, теги и production не менять без отдельного решения.

### Очередь внешних кандидатов

Проверка использует `w1zardz/amnezia-vpn-russia-split-tunneling/data/external-candidates.json`.
Она **не добавляет** домены в `geosite:ru`; сверяет их с готовым DAT и прикладывает `geosite_RU_external_candidate_audit.md` к CI архиву.

Результаты `uncovered_with_upstream_warning` не должны автоматически импортироваться: это могут быть зарубежные адреса, глобальный CDN, исчезнувшие DNS-записи или другие отклонения источника.

Примеры кандидатов, которые оставлены на ручную проверку: `2gis.io`, `2gis.qa`, `2gis.sa`, `avito.net`, `rutube.io`, `vtbcapital.com`, `sbrf.com`, `t-cdn.net`. Для `avito.net` обнаружены признаки доменной парковки (не следует воспринимать созвучие бренду как доказательство принадлежности). Другие не принимаются без актуального подтверждения.
