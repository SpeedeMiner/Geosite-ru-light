# GeoSite RU Light v11.19

Добавлены 83 точных имени сервисов, которые сообщают клиенту его внешний IP-адрес. Каждое правило имеет тип `full:`, поэтому поддомены и другие хосты тех же владельцев не затрагиваются. Источник данных — публичная HTTPS-проверка и [журнал исследования](https://github.com/SpeedeMiner/Geosite-ru-light/blob/bd11257cf3f6a83af4631df22b04acca3aece24a/docs/research/2026-11-14-wide-post-v11-18/get-audit/ip-check-20261115-03/README.md).

Для 67 из 83 имён дополнительно подтверждено, что сервис показывает фактический IPv4 выхода в двух российских ASN; ещё три подтвердились в одной сети. Часть сервисов рассчитана на IPv6 и не отвечает по IPv4 с проверенных выходов.

Выпуск содержит многокатегорийный DAT и SRS для sing-box. Категория `RU` дополнена только точными хостами, а остальные правила сборки сохранены. Синхронизация GeoSite RU Server берёт эту номерную версию Light и оставляет в серверном DAT одну категорию `RU`.
