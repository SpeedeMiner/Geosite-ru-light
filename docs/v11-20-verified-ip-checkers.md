# GeoSite RU Light v11.20

Добавлены два точных правила RU: `full:api.tgip.eu` и
`full:ipv4.ippubblico.org`. Они не охватывают другие имена этих операторов.

Оба сервиса вернули фактический IPv4 выхода в четырёх проверенных HTTPS 200
из двух независимых российских ASN, AS12389 и AS52043. Измерения выполнены
строгим GET через VPNObratno без Globalping. Результаты не означают
доступность с любой российской линии.
[Таблица и квитанция прогона](https://github.com/SpeedeMiner/Geosite-ru-light/tree/f2fdbf2d66fb21f1be049ee7b43c4493b4988fa7/docs/research/2026-11-14-wide-post-v11-18/get-audit/ip-check-20261115-04).

Сборка сохраняет все правила v11.19, меняя только два точных правила RU.
BLOCK и остальные 16 категорий, включая все Hydra-правила, не меняются.
