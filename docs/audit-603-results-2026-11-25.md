## Метод и ограничения

- Исходные группы: 393 имени с адресами; 45 NXDOMAIN; 141 с NODATA/прочими DNS-исходами; 24 с DNS-ошибками. Для последних 210 повторно запрошены A, AAAA, CNAME, MX, NS, SOA и SRV для `_sip._tcp`, а A/AAAA — через два рекурсивных резолвера. Нельзя считать один шаблон SRV проверкой всех возможных сервисов.
- Для 45 ранее NXDOMAIN отдельно проверены авторитетные серверы фактической зоны имени. Родительский регистрируемый домен и само имя учитываются раздельно; RDAP и WHOIS доступны не для каждой зоны.
- 393 имени проверены из двух российских ASN и из точки США: Chrome uTLS с проверкой сертификатов, HTTP/2, HTTP/1.1, HTTP/80, SNI и Host, ограниченное чтение ответа и переходы по редиректам; до двух IPv4 и одного IPv6 на имя. При отсутствии второго ASN у 15 имён выполнен выборочный повтор только из другого ASN.
- IPv6-попытки в проверявшихся окружениях преимущественно завершались отсутствием маршрута. Это не доказательство неисправности IPv6 у сервисов. Часть TLS/ALPN-согласований завершилась ошибкой; они сохранены как ошибки, а не как подтверждение недоступности.
- Например, `myipaddress.site` вернул HTTPS 200 в США и таймауты в двух российских VPN-сетях. Это различие не позволяет отделить географическую политику от временной неисправности, WAF или репутации VPN-IP. Подтверждённых GEO_BLOCKED нет; ноль не означает отсутствие геоблокировок.
- Первоначальный workflow сохранил частичные артефакты, но статус ряда партий был failure из-за кода адаптера, а первый сборщик ошибся на пустом списке попыток. Данные повторно собраны без полного сетевого прогона; проверены принадлежность партий и наличие двух ASN для каждого из 393 имён.
- Статистика для всех **4 495** имён ниже относится к исходному аудированному DAT. После последующего PR №47 29 из исходных 31 незарегистрированного имени уже исключены из действующей базы; пользовательские данные маршрутизации этим аудитом не менялись.
