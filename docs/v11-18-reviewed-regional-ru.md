# GeoSite RU Light v11.18

- 406 точных имён в категории RU добавлены поверх v11.17. Ни одно опубликованное покрытие не удалено. Поддомены автоматически не включаются.
- Завершена последняя очередь из девяти URL и четырёх альтернативных страниц. В заключительном проходе подтверждён отдельно корневой doshirak.com, WWW уже входит в общий набор 406.
- В Light DAT 4 252 правила RU, в Server DAT 4 140 правило и единственная категория RU. Остальные 17 категорий SRS не изменились.
- Сохранены прежние входные снимки, BLOCK, категории Hydra и политика Server. Пройдены семантическое сравнение покрытия, проверка sing-box и офлайн-восстановление пяти файлов.
- Базовый снимок для отката — v11.17.
