# Очередь GeoSite закрыта для v11.18

Обработаны все девять ранее закреплённых URL и четыре альтернативных пути для неясных результатов. Получено 39 наблюдений из трёх независимых ASN РФ. По итогам добавлено ровно одно ранее не покрытое имя — doshirak.com. WWW этого же имени уже присутствовал в +406.

- Borealis: обе страницы корня остановились в навигации и на заголовке. На WWW HTTP не получен. Мурман Фиш и Botanica: две страницы каждого имени не дали полного основного содержимого в снимке.
- Murmantara: корень и страница истории показали HTTP 403 с сообщением о приостановке работы. Это не доказательство сетевой блокировки. Новый домен .ru не был частью очереди.
- Linar Massilly: HTTP 200 с настоящей заглушкой техработ, не рабочий сайт. У Эталона и Оазиса основное содержимое не подтвердилось.

В релиз идёт +406 относительно v11.17 после исключения одного ранее неопубликованного имени без подтверждённого основного содержимого. Неподтверждённые сайты остаются вне добавлений. Исходная очередь не переоткрывается автоматически.
