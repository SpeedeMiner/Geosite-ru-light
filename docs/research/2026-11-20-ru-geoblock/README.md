# GeoSite Light: проверка региональных ограничений 20 ноября 2026

## Решение по Habr

Убрать `domain:habr.com` из категории `RU`, включая поддомены. В опубликованном DAT v11.21 суффикс попадал в `RU` через выбранные категории `runetfreedom|habr` и `mvrvntn|category-ru`. Исключение проверяет сборщик, валидатор DAT и публикационный gate. Gate принимает потерю только этого исторического суффикса и не разрешает вернуть покрытие через дочернее правило или более широкий суффикс.

Один и тот же [URL статьи](https://habr.com/ru/articles/870110/) вернул `451` из AS12389 и AS8359 и `200` с заголовком статьи из Нидерландов. TLS проверен во всех трёх случаях. При этом публичная лента Хабра отдала `200` в двух других российских ASN. Следовательно, ограничение не относится ко всему сайту. Сам Хабр [описывает блокировку отдельных публикаций по стране IP](https://habr.com/ru/docs/help/451/).

`habrastorage.org` оставлен отдельно. HTTPS GET конкретного изображения со страницы статьи дал `200 image/jpeg` с проверенным TLS в AS3216, AS49505 и в Нидерландах.

Проверенная дельта к v11.21 — **4 619 → 4 618 правил RU**, ровно `−domain:habr.com`. Остальные 17 категорий, их SRS и MRS побайтно совпали с опубликованными. Исторический номерной выпуск не пересобирается. SHA-256 кандидата DAT — `027939e3a31591bd48a57428c893a8237fe61352d90a8c3077b39366a3a3d0cc`.

## Остальные кандидаты

Взяты все 25 имён из пересечения `RU` опубликованного DAT с `CATEGORY-GEOBLOCK-RU` двух закреплённых источников (Hydra и mvrvntn). Проверка учитывает эффективное покрытие, включая компактные суффиксы `ru`, `by` и `kz`. Всего проведено 42 публичных HTTPS GET-замера URL, по три узла на замер. Учитывались тело или тип ожидаемого контента, валидность TLS и редиректы. Список-источник, 403 без объяснения, DNS-сбой или таймаут сами по себе не классифицировались как GeoIP.

Кроме Habr, **в проверенной выборке не подтверждён отказ самого сайта по GeoIP**. Три сетевые блокировки задокументированы отдельно. Дополнительные правила в этой правке не меняются. Чтобы вывести отдельные имена из общего суффикса `ru`, не ломая правило для остальных адресов, требуется отдельное правило с более высоким приоритетом в клиенте.

[Таблица всех наблюдений и ссылки на измерения](observations.tsv). Это проверка публичных URL из конкретных сетей, не всей зоны и не функций за авторизацией.
