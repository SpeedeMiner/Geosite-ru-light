# Точка продолжения · GeoSite +393

Проверено 45 новых точных HTTPS URL в семи волнах. Для каждого сохранены три наблюдения на ASN 3216, 12389 и 207957, всего 135 наблюдений. Из 45 три приняты в кандидат, 42 удержаны: 19 без читаемого содержимого, 13 с редиректом, 5 с ошибкой TLS/транспорта, 4 после ручной проверки содержимого, 1 с HTTP не 200. Удержание не означает блокировку сайта.

Новые подтверждения:

- `www.biooperations.com` — казахстанский завод BioOperations, его контакты видны на всех трёх пробах. Apex отдельно перенаправляет на HTTP.
- `qazexpocentre.com` — контакты казахстанского оператора в Астане. Точный отдельный заводской сайт не принят по результатам этой волны.
- `saulecompany.com` — казахстанская КФ Saule, оператор подтверждён независимой карточкой, во всех трёх сетях видна содержательная страница об оптовых продажах и экспорте. WWW перенаправляет на apex и отдельным правилом не добавлен.

Продолжить с [10 закреплённых альтернативных URL](16-next-exact.tsv). Все десять имён не покрыты RU в DAT +393, URL не повторяют ни одного из 497 исторических HTTPS URL. Очередь ещё не отправлена. После фактической проверки квоты на неё нужно 30 проб плюс сохранённый резерв 19. Дата и время измерений приведены в JSONL UTC. Для применения результатов требуется новое решение по каждому точному имени.
