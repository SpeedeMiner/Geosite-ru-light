# Источники и ограничения третьего окна

Матрицы охвата хранят источник на каждой строке, а JSONL — исходный точный URL, ID и результаты трёх сетей. Этот файл фиксирует также источники, не давшие пригодного списка сайтов.

| Источник | Итог |
| --- | --- |
| КАИТК, https://reestr.itk.kz/ и https://www.2020.itk.kz/ru/uchastniki-kaitk | Прямое получение веб-страницы истекло по тайм-ауту. Полную выборку не заявляем. |
| РУССОФТ, https://russoft.org/members/ | Публичный индекс предоставил страницу с навигацией, но не пригодную для полного извлечения таблицу сайтов. Прямая загрузка истекла по тайм-ауту. Отдельные записи не подменялись догадками по названиям. |
| АРИР, https://interactivead.ru/members/ | В доступном представлении членский список показан изображениями, без набора явных сайтов организаций. Не пытались открывать закрытый раздел. |
| АКИТ, https://www.akit.ru/about/about-us и https://www.akit.ru/about/documents | Найдены страницы ассоциации и датированный PDF списка, но не подтверждён полный актуальный список публичных адресов компаний. |
| АПКИТ, https://apkit.ru/about/members/ | Извлечено ровно 114 ссылок из карточек участников, внешние ссылки шапки и подвала исключены. HTTP в аналитической матрице приведён к HTTPS только для сравнения имён; факт ответа фиксируется отдельно. |
| Союз зернопроизводителей, https://growers.kz/pages/spisok-uchastnikov/ | Доступная таблица даёт названия предприятий, но не пакеты сайтов. Не извлекали сайты из имён, адресов почты или карты. |
| Продкорпорация, https://fcc.kz/ru/o-korporaczii/korporativnoe-upravlenie/dochernie-organizaczii/ | Найдены прямые ссылки на дочерние предприятия. Официальная ссылка не исправляет TLS у akbiday.com, который остался вне кандидата. |
| BELARUS AgroBelarus и Экспоцентр | Каталог использован как отраслевой указатель, а явные адреса Савушкина и Бабушкиной крынки сверены через карточки гильдии и выставки. Оба домена уже под суффиксом BY. |
| AssПО, https://apo.kz/participants | Пригодна как ссылка на ассоциацию, не как точная машинная выборка всех адресов участников. Не добавляли неизвестные сайты по логотипам. |
| PharmaTech Iteca | Результаты всех 28 попыток и принадлежность карточек сохранены в отдельной таблице. Пустое поле Website и тайм-аут обрабатываются как разные состояния. |

Три проверенные ASN относятся к российским точкам измерения, но они не представляют все российские сети. Для повторной проверки известных проблем не следует отключать TLS или считать HTTP 200 доказательством работоспособности сервиса.
