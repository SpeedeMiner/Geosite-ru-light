# ЭДО, закупки и региональные рабочие адреса, 16.11.2026

Старт от [очереди +117](../epd-operator-20261116-1324/candidate-plus117.txt). [Очередь +128](candidate-plus128.txt) добавляет 11 точных `full:`, сохраняет все +117 и не создаёт пересечений с BLOCK. [Поштучные решения](decisions.tsv) проверены по строгому TLS и тому же публичному URL минимум из двух российских ASN. Для перенаправления проверялся конечный путь в тех же сетях.

## Не включены или уже покрыты

- КОМИТА. [Реестр ИС ЭПД Минтранса](https://mintrans.gov.ru/activities/376/377/380) в проверенном снимке отмечает подключение как «В процессе». [Росстат](https://24.rosstat.gov.ru/folder/50867) указывает `www.comita.ru`, этот адрес подтверждён и уже покрыт. `etp.comita.ru` — электронная торговая площадка, а не продуктивный вход ИС ЭПД. Новый публичный вход ИС ЭПД не найден.
- Veeroute. `veeroute.com` не прошёл полный GET на главной и коротком /how-it-works в текущих повторных сетях. [Международная страница](https://veeroute.com/company/) среди контактов указывает VRT Global Limited на Кипре. Старый `docs.veeroute.com` дал два строгих 503. Действующие `.cloud` из +117 остаются без изменений.
- Tender.Pro. Публичные регистрация и FAQ на WWW дали повторяемый 503 c одинаковой страницей «Testing…». Apex редиректит на WWW. Уже покрытая `help.tender.pro` возвращает содержательный 200.
- Supl.biz. Несколько известных публичных путей дали 302 на тот же URL. Это не доказательство блокировки и не основание включать домен.
- Documentolog. `apicom.documentolog.com/` дал два 404. `apibusiness.documentolog.com` опубликован в API-инструкциях, но безопасный публичный содержательный путь на нём не подтверждён. Вызовы авторизации, подписи или любые операции с документами не выполнялись.
- Edisoft. Три страницы казахстанского раздела полностью получены из двух российских ASN. Тот же FQDN обслуживает [Кипр](https://edisoft.io/en-cy/products/edisoft-platform) и [Литву](https://edisoft.io/lt-lt/apie-mus/kontaktai). Для точного доменного правила нельзя ограничиться /ru-kz, отдельный публичный рабочий хост пока не подтверждён.
- [Сверка приложения к соглашению Диадока](operator-coverage.tsv). Все девять BY/KZ-адресов из десяти строк уже покрыты двумя DAT. `unicon.uz` не включён автоматически по факту партнёрства. Старый путь справки МетаЭры дал два 404. Уже покрытые Sign.Me и ЛераДата проверены как контроль без повторного добавления. Результаты контрольных 401/403 и TLS-ошибок не интерпретируются как блокировка.

[Доказательства, метрики и SHA-256 архивов](wave-summary.json): 16 групп, 186 наблюдений по 85 URL, 171 завершённый HTTP-ответ со строгим TLS из AS3216, AS8402, AS12389, AS28840 и AS34974. У одного первого прогона Seldon не было явного результата RIPEstat для второго ASN, эти строки оставлены как наблюдения, а правила подтверждены в двух других прогонах. Проверка не включает IPv6, успешный вход, регистрацию и операции с документами. [Наблюдавшиеся адреса и BGP origin](observed-origins-final.jsonl) приведены для атрибуции измерений, а не для добавления IP-префиксов. Опубликованный v11.20, `main` и `release` обеих сборок сохранены. [Предпросмотр DAT](dat-preview.tsv): RU Light 4447 → 4575, Server 4335 → 4463. [18 SRS](srs-preview.tsv) прошли обратную проверку, 17 иных категорий совпали побайтно. 4 теста SRS, 13 Server и 16 транспортных тестов прошли. [Публичные refs](publication-guard.tsv). Релиз не запускался, GeoIP не менялся.

Следующая точка: отдельные опубликованные рабочие входы казахстанских операторов, ещё не покрытые .kz, и страницы Supl.biz после выяснения канонической HTTPS-цепочки. КОМИТА пересмотреть по появлению первичного руководства именно ИС ЭПД.
