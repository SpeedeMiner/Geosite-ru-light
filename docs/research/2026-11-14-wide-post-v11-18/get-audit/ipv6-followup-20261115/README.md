# Проверка IPv6 IP-эхо на подтверждённом российском выходе

Этот каталог продолжает два прогона IPv4 от 15 ноября 2026. Он не меняет
правила RU и не подменяет измерения из VPN на результаты DNS. В
[ipv6-dns.tsv](ipv6-dns.tsv) есть 40 запросов A/AAAA из двух DNS-over-HTTPS
резолверов. В отдельных запросах Cloudflare ответ не удалось получить,
поэтому там сохранён `query_unproven`. Это не означает отсутствия записи.

VPNObratno в ранее использованном закреплённом раннере разрешает только
IPv4-трафик. Из восьми проверенных публичных IP UDP-профилей ни один
не задавал IPv6 явно. Это не исключает опции, которые может отправить сервер,
но нет оснований убирать запрет на внешний IPv6 в существующем раннере.

## Запуск на разрешённом сервере с публичным IPv6

Из корня этого исследовательского checkout, с обычным пользователем,
Python 3.10+ и curl с поддержкой `%{json}`. Укажите фактический ожидаемый
ASN выхода, а не ASN назначения. Адрес интерфейса не передаётся в CLI.

```sh
audit=docs/research/2026-11-14-wide-post-v11-18/get-audit
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH="$audit" \
  python -B "$audit/ipv6-followup-20261115/ipv6_echo_audit.py" \
  --expected-asn AS207957 --output ipv6-echo-result.json
```

AS207957 приведён как пример. Для зачёта результаты ipify и IPinfo должны
показать один публичный IPv6, совпадающий с локальным адресом обоих
соединений. IPinfo должен показать RU и ожидаемый ASN, а RIPE RIS —
однозначный BGP origin этого же ASN. До подтверждения ни один из десяти
чекеров не запрашивается. Записываются HTTP-коды, результаты TLS и
сопоставления, без тела ответа, адресов клиента/сервера или префикса.
После десяти GET снова проверяется выход. Прокси, редиректы, выключение
проверки сертификата и переход на IPv4 не используются.

RIPEstat передаётся только адрес уже измеряющего сервера для поиска BGP
origin. Страна IPinfo и BGP origin — подтверждение точки наблюдения, не
доказательство страны хостинга целевых сервисов или домашнего тарифа.
Результат одного выхода не переносится на всю РФ.

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH="$audit:$audit/ipv6-followup-20261115" \
  python -B -m unittest discover -s "$audit/ipv6-followup-20261115" -q
```

В рабочем окружении предзапуск остановился с `preflight_unverified`.
HTTPS-ответов из RU IPv6 в отчёте пока нет. Существующий VPN-раннер и
GeoIP PR №5 не задействованы и не изменены.
