# GeoSite — крупные российские операторы, 15 ноября 2026

## Результат

Два новых подтверждённых точных имени: `api.curator.pro` для публичного
HTML-справочника Curator и `docs.solarspace.pro` для справки Solar Space.
У каждого ожидаемый заголовок в двух выходных ASN, строгий TLS и 206
на заранее ограниченную публичную выборку. Не проверялись вызовы
API, авторизованные кабинеты, платежи или пользовательская активность.

В 114 уникальных исходных URL было 64 URL с HTTP 200, нулевым
результатом curl и валидным TLS из рабочего окружения. В 333
парах «источник — хост» 170 имён, из которых 141 покрыто обоими
выпущенными DAT, 7 уже находятся в сводной исследовательской очереди
(включая 2 добавленных в этом окне), 22 оставлены вне обеих групп.
В число последних входят не только российские сервисы, но и
партнёры, внешние ссылки и отдельные категории. Проверка
каталогов и ответы из рабочих сетей не означают прямую доступность из РФ.
