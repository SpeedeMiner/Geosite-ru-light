Обычные VPN-прогоны используют точный GET IPv4 с проверкой имени и цепочки TLS, без следования за редиректами. Выходные IP не включены в публичные таблицы. Статус HTTP, `curl_exit` и выборка тела — разные показатели. SHA-256 тела относится только к сохранённой выборке. Public DNS/HTTP с Actions не доказывает доступность из России, а наличие AAAA либо её отсутствие не доказывает доступность по IPv6.

`domain:selcdn.net` оставлен в действующем правиле. Клиентские технические хосты не считаются собственными доменами Selectel и не образуют новую очередь. Широкий суффикс LiveDigital не предлагается, медиапотоки, авторизация и работа вебинарной комнаты не проверялись.
