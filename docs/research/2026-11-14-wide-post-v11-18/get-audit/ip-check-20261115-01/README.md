# IP-чекеры вне RU

Проверены внешние IP-эхо, API геолокации собственного адреса, браузерные
IP-чекеры и страницы диагностики. Источники перечислены для каждого
URL в матрице. Полученные адреса и тела ответов не сохранены в Git.

- [Матрица](coverage.tsv) сравнивает 192 URL / 182 имени с опубликованными
  Light и Server DAT до смены Light. Учитываются точные и суффиксные
  правила, BLOCK, другие категории Light и прежний preview.
- [Все 41 пропуск](missing-both.tsv) отражает исходный и повторный GET.
  Успешный `echo` требует HTTPS 200 с проверенным TLS и адресом в
  ожидаемом текстовом, JSON или trace-поле. Суффикс `v4` / `v6` — это
  версия возвращённого адреса, а не подтверждение транспорта или
  доступности из России. Браузерная страница с упоминанием IP не
  засчитывается как работающий программный IP-эхо.
- [14 подтверждённых кандидатов](confirmed-echo.tsv) не добавлены.
  `www.cloudflare.com` и `one.one.one.one` тоже вернули адрес на
  `/cdn-cgi/trace`, но правило GeoSite затронуло бы весь хост.
  `www.my-ip-address.com` перенаправляет на HugeDomains.
- [PR #35](https://github.com/SpeedeMiner/Geosite-ru-light/pull/35)
  добавил только `full:ip.nnev.de` и `full:ip.oxylabs.io`. Оба
  повторных GET вернули IP. В [Light latest-optimized](https://github.com/SpeedeMiner/Geosite-ru-light/releases/tag/latest-optimized)
  совпадают DAT и RU SRS из успешно проверенного артефакта PR.
  Server штатно синхронизирует только номерные выпуски Light. Его
  проектор локально воспроизвёл ровно те же две добавки, но текущий
  Server DAT пока их не включает. v11.18 не переписывался.

Доступность измерена из рабочего окружения, без подтверждённого
российского ASN. Таймаут или ошибка прокси не доказывают блокировку
либо недоступность сервиса из нужной сети.
