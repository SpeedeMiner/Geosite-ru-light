# Окно 04 — IP-чекеры после v11.19

[Матрица](coverage.tsv) сверяет 61 точное имя с обоими опубликованными DAT и
587 хостами из прошлых TSV. Покрытые и ранее просмотренные имена не измеряются
повторно. HTTPS CONNECT из рабочего окружения проверяет ответ и TLS, но
два контрольных сервиса не подтвердили единый IPv4 выхода. Совпадение в
ответе с известным выходом здесь не зачитывается. В таблице нет IP и тел.

Два выделенных сервиса с собственной документацией и полным ответом HTTPS 200
проверяются [одной VPN-партией](vpn-plan.tsv). `ipadd.cn` и `api.jinshaxinxi.cn`
оставлены отдельно из-за других функций на тех же хостах. У `ipinfo.now`
замечено поле `ip_addr`, у `api.tion.kr` в другой попытке — метка `myip`.
Работа этих форматов и совпадение с выходом не проверены. Результат через
рабочий HTTPS CONNECT не подтверждает, что цель достигнута по IPv6.
