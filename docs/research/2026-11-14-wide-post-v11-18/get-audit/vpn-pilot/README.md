# Пилот GeoSite через VPN без Globalping

`vpn_get.py` выполняет обычный HTTPS GET к сайту из сохранённой очереди.
В отличие от `audit.py`, этот инструмент не обращается к Globalping.
Он не скачивает VPN-профили и не поднимает VPN автоматически. Требуется
уже работающий локальный SOCKS5-вход Xray, sing-box или другого клиента,
закреплённый за одним выходом. Для тестового входа настройте один outbound
без правил DIRECT и без автоматического переключения на другой выход.
Настройки роутинга самого клиента скрипт проверить не может.

Из каталога `get-audit` на машине с запущенным клиентом выполните:

```sh
python3 -B vpn_get.py vpn-pilot/first-get.tsv /tmp/geosite-vpn-ru-as207957-01 \
  --socks 127.0.0.1:10808 --expect-ip "$VPN_EXIT_IP" --expect-asn AS207957 --country RU
```

Подставьте фактический локальный SOCKS-порт и публичный IP выхода, а не
адрес сервера подключения. Для каждого выхода используйте новый каталог.
IP, ASN и код страны должны совпасть в двух ответах сервисов метаданных
и с ожидаемыми значениями как **до**, так и **после** партии. Проверки
метаданных тоже идут через SOCKS. Они не выполняют GET сайтов из очереди.
Если один сервис метаданных недоступен или вернул другое значение,
партия останавливается либо сохраняется отдельно как неподтверждённая.

SOCKS5 получает исходный hostname, без предварительного резолвинга в
curl. Куда направляет DNS и запрос сам VPN-клиент, зависит от его настроек.
Проверка имени и цепочки TLS остаётся включённой. Запросы не отправляют
учётные данные, не переходят по редиректам и не повторяются через сеть
рабочей среды. В записи не принимается порт SOCKS за семейство IP
целевого сайта. Результаты идут отдельным слоем `single_vpn_exit`, не в
счётчик Globalping или домашнего доступа. Перед публикацией отчёта
проверьте, можно ли раскрывать записанный публичный IP выхода.

В этом рабочем окружении OpenVPN/netns недоступны, а локальный SOCKS5
не запущен. [Пробный запуск](workspace-preflight.json) завершился до
первого сайта. Локальный интеграционный тест не имитирует российскую
доступность, но проверяет реальную передачу имени по SOCKS5, HTTPS GET с
путём и параметрами, строгий TLS и отсутствие автоматического редиректа.
