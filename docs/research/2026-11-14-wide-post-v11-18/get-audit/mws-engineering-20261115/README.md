Поля `light_ru`, `server_ru`, `block`, `non_ru` описывают совпадения в проверяемых базах. `NA` не означает пригодность для DIRECT. Для тестов публикуются хэши, коды и безопасные части URL, не публикуются тела запросов или параметры перенаправлений.

`taiga-ui.dev` связан с публичным проектом и каталогом Т-Банка. Наблюдаемые A/AAAA совпали с официальным пулом [GitHub Pages](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site) и пришли из AS54113. Это общий хостинг, не ASN Т-Банка. Из AS33991 и AS42610 открылись обе страницы. Добавлен только точный хост. Платформа и обнаруженные в HTML общие хосты ресурсов не меняются.

`www.nexign.com` и канонический `nexign.com` наблюдались на AS48102. В рабочей сети проверены три отдельные операции без автоматического перехода: HTTPS WWW → HTTP корень, HTTP корень → HTTPS корень, HTTPS корень → 200. WWW оставлен вне очереди из-за снижения схемы, клиентский портал — из-за 403. `neonhrm.nexign.com`, `job.nexign.com`, `tdata.tech` и `docs.tdata.tech` уже находятся в предыдущей очереди, дубликатов нет.

## Итог

[Решения по хостам](decisions.tsv) · [Taiga UI и повтор DivKit](vpn-43733641857.tsv) · [квитанция](vpn-43733641857-receipt.json) · [новый пакет +60](stacked-sixty.txt) · [проверка DAT/SRS](full-build-replay-sixty.tsv).

В пяти прогонах 54 HTTPS-запроса и 38 HTTP-ответов. HTTP-ответ не означает успех: в числе этих ответов есть 301, 302 и 403. Все три правила включены только в исследовательский список. Ни URL перенаправления, ни IPv4/IPv6-наборы платформ не являются добавлениями. DNS/RIS включает обе IP-семьи, но HTTPS пилот проверяет IPv4. Оценка фактической доступности по RU IPv6 — отдельная задача.
