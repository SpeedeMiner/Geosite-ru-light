# Сверка GeoSite v11.18 через GET

Этот аудит не меняет маршрутизацию, PR GeoIP №5, release или теги. Из диагностики PR №5 взяты раздельные наблюдения по ASN, семействам IP и отсутствие автоматической трактовки тайм-аута как блокировки. Сетевой код выполняет только DNS и обычный HTTPS GET к опубликованной странице. ASN 3216, 12389 и 207957 в RU, по одной точке на ASN. Состав точек проверяется по фактическому ответу. Метка сети не считается свидетельством домашнего подключения.

- **inventory.json**, **baseline-exact.tsv** и **suffix-inventory.tsv** — инвентарь из проверенных DAT. Точные правила Light и Server совпадают. Суффиксы исследуются выборкой и не отправляются как цели (например, `ru` никогда не становится URL). Неизвестный путь точного имени обозначен корнем `/`, это тест главной страницы, не всего сервиса.
- **pilot.tsv** — 19 отложенных целей, 31 имя кандидата, 6 точных имён из релиза, пять подстановок для суффиксов и одна контрольная цель. **baseline-batch-001.tsv** — ещё пять точных имён из DAT.
- **dns-dual-stack.tsv** — пять диагностических целей для независимых A/AAAA и IPv6. Запись AAAA не означает успешный IPv6 GET. Семейство GET сверяется с адресом из ответа.
- **archive-reviewed.tsv** — переразбор старых захватов. Это не свежий сетевой прогон. **archive-dispositions.tsv** — промежуточный отчёт до исправления ложного распознавания веб-заглушки. Пользоваться следует `archive-reviewed.tsv`.
- Для свежих результатов исходный редирект и его объявленная цель сохраняются, но не обходятся автоматически. Ни HTTP 200, ни найденный текстовый маркер не являются автоматическим допуском в RU. Обрезанный HTML или бездействующие точки помечаются отдельно. API возвращает текстовую копию ответа, исходные байты Windows-1251 из уже испорченной строки восстановить нельзя.
- Для независимого продолжения --size 50 делит инвентарь на группы до 150 проб IPv4. Перед запуском проверяется квота. При её исчерпании скрипт не посылает пробы, не меняет учётную запись и не использует другой выход. Не запускайте сразу все партии, если квоты не хватает.

```sh
python3 -m unittest -v test_audit.py
python3 audit.py pilot.tsv results-pilot.jsonl --reserve 10
python3 audit.py dns-dual-stack.tsv results-dns.jsonl --test a --test aaaa --test get6
python3 audit.py baseline-batch-001.tsv results-baseline-001.jsonl
python3 batches.py baseline-exact.tsv remaining --exclude pilot.tsv --exclude baseline-batch-001.tsv
```
