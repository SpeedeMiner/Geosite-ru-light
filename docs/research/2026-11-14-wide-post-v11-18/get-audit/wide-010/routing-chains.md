# Геоданные, отраслевые сервисы и публичные реестры

Покрытие определено по опубликованным DAT v11.18 Light и Server. Стрелка из
обычной ссылки не означает HTTP-редирект, а наличие страницы в индексе
не подтверждает её доступность из России. Ниже изложены основания для
одного GET на точный URL, не предложение нового общего суффикса.

| Источник | Точная цель | Что известно и что проверить |
|---|---|---|
| [Интернет-портал СНГ](https://e-cis.info/news/564/132446/) | [Геопортал](https://cisgeo.info/) | Прямая ссылка и сообщение о вводе в эксплуатацию. Оба точных имени вне RU. У корня `e-cis.info` в окне 008 все три HTTP 200 без ожидаемого идентификатора, а теперь есть предметная статья с сильным маркером. На карте сторонний `mc.yandex.ru` уже в BLOCK и не является обязательным покрытием. |
| [Публичный сайт МАК](https://mak.ru/) | [О МАК](https://mak-iac.org/o-mak/) | На покрытом сайте есть обычная ссылка на непокрытый хост. Старый и новый сайты не считать одним правилом или доказанным редиректом. |
| [Справочник МБМВ](https://www.bipm.org/en/liaison/regional/coomet) | [КООМЕТ](https://coomet.info/) | Международный профиль прямо указывает `coomet.info`. На нём есть ссылка на покрытый `easc.by`. Конкурирующий `www.coomet.net` не добавлен в очередь. |
| [Профиль ЕАПВ в руководстве ВОИС](https://pctlegal.wipo.int/eGuide/eqe/view-doc.xhtml?doc-code=EA&doc-lang=EN&doc-type=annex) | [Ресурсы ЕАПВ](https://www.eapo.org/informational-resources/) | WWW даёт отдельные ссылки на `www.eapatis.com` и `services.eapo.org/attorneys`, тоже вне RU. У первого веб-индексатор получил 403, у второго видит оболочку. Ни один исход не подтверждает доступность из трёх ASN. |
| `portal.eaeunion.org/` | [Открытые данные ЕАЭС](https://opendata.eaeunion.org/) | Единственный уже измеренный HTTP-редирект в таблице. Все три ASN вернули 301, ID `22sDmvaJK1xAVzU5I00021VVA`. Точный корень не наблюдался, прежние 200 без достаточного тела относятся к другому пути `/opendata/ru/resourses`. |
| `docs.eaeunion.org/` | [Карточка решения № 120](https://docs.eaeunion.org/documents/414/7596/) | По корню три 200 и маркер есть, ID `21A9OES8nl36yPkyu00021VVA`. Глубокий путь проверяет работу навигации, не новый кандидат по имени и не действие с подписью. |

Успешный HTTP, сертификат TLS и соответствие имени понадобятся вместе.
Ответы 403, таймауты и оболочки SPA остаются самостоятельными исходами.
