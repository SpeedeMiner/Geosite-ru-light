# IP-эхо, окно 03

Промежуточный снимок, 15 ноября 2026. Текущий опубликованный Light и номерной
Server сверены по SHA-256. В очереди только новые точные хосты без совпадения
с RU в обоих DAT. Предыдущие окна 01 и 02 исключены. В первых двух партиях
49 таких хостов и 8 кандидатов одного прохода. Семьи в теле ответа не
подтверждают транспорт IPv6. GET выполняется из рабочего окружения, без
установления российского ASN. Политика RU и релизы не изменялись.

### Партии 03–05

Восстановлены [03](03/summary.json), [04](04/summary.json) и [05](05/summary.json).
Проверены суммы исходных списков и обоих DAT, уникальность новых имён и
соответствие всех шести кандидатов конкретным наблюдениям TLS/HTTP 200.
Из 12 новых имён в этих партиях шесть дали эхо. Всего по партиям 01–05
61 новый пропуск и 14 хостов с IP в теле ответа. Накопительно с окнами
01 и 02 это 55 отдельных имён.

### Продолжение, партии 06–09

Сверка Light и Server выполнена с контрольными суммами из
[партии 09](09/summary.json). Партия 06 добавила три хоста с IP в ответе,
07 добавила шесть, 08 добавила 17 после проверки назначения хостов,
09 уточнила ещё два из ранее просмотренных хостов. Во всех трёх окнах
получилось **83 уникальных кандидата** без перекрытий. [Индивидуальные
наблюдения](08/observations.tsv) сохраняют результат строгой TLS проверки.

[VPN-прогон 43706440358](vpn-43706440358/summary.json) сравнил IP в теле
с реальным IPv4 выходов МГТС и Дом.ру для 60 URL. Совпадение из двух
сетей подтвердилось у 47 URL, из одной у трёх. [VPN-прогон
43707177248](vpn-43707177248/summary.json) проверил ещё 26 URL из МГТС
и AS34168. Совпадение из двух сетей получено у 20 URL. Все исходные
архивы проверены по SHA-256 и по точному составу URL, результаты
сохранены без адресов выхода и тел ответов. Оба прогона не расходовали
квоту Globalping.

Неполучение A-записи у хостов, рассчитанных на IPv6, отмечено как
отдельная задача. Чекер с ответом только на конкретном пути общего
хоста остался в [списке для разбора](08/missing-new.tsv).
