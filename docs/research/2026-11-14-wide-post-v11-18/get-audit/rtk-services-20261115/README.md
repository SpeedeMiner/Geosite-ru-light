У `wiki.domru.biz` две страницы вернули четыре ожидаемых ответа TLS/200 через AS12389 и AS44724. A-адрес наблюдался в префиксе AS31483. Новое правило ограничено публичной справкой. Клиентские хосты АТС, медиа и регистрация не проверялись. `mtfree.net` не прошёл строгий TLS на обоих выходах, остаётся вне очереди.

У «Планеты» первый прогон дал ожидаемые результаты только из AS196949. Для AS49531 RIS origin отсутствовал и ни один URL не дал HTTP. Повтор из AS12389 и AS44724 подтвердил шесть хостов. Главная, помощь, вакансии и Wink дали ожидаемые 200, два старых поддомена — HTTPS/301 на основной сайт. TV остаётся вне списка.

У МТС Линк `we.study` и `www.we.study` используют общую сеть AS13335. Наблюдавшиеся A у `comdi.com`, `www.comdi.com`, `broadcast.comdi.com`, `jespo.co` и `wsboard.jespo.co` анонсируются AS34545. Не сравнивать эти классы как единый IP-набор. Для WSS запрос HTTPS без апгрейда не доказывает работоспособность Вебсокета.

`dmp.one` из HTML РТКомм — сторонняя аналитика/идентификация посетителей, не корпоративное приложение. Скопированные из справок примеры доменов SDK и интеграции не превращаются в DIRECT. Никакие запросы на динамические трекерные пути или URL с параметрами в измерительную выборку не попадали.
