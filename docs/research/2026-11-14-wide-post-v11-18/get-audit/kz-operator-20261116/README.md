# Рабочие адреса операторов Казахстана и Supl.biz, 16.11.2026

Старт от [очереди +128](../edo-transport-20261116-1356/candidate-plus128.txt). [Выборка 41 FQDN](coverage.tsv): 30 уже в обоих релизных DAT, ещё четыре уже в +128, семь — вне RU и BLOCK. [Доказательства по каждому имени](decisions.tsv). Предлагаются пять точных имён, то есть [очередь +133](candidate-plus133.txt). Никаких новых суффиксов.

- **Supl.biz.** В AS12389 и AS28840 один и тот же публичный FAQ, главная и оферта Казахстана дали 302 на тот же URL, затем полноценный 200 при сохранении анонимной cookie. HTTPS не ослаблялся, учётные данные и формы не использовались, значения cookie не сохранялись в отчёт. Подтверждён опубликованный WWW-алиас и его конечный хост. Отдельный `cdn.supl.biz` отдал одно и то же опубликованное PNG в двух сетях с завершённым GET; выборки первых 10 000 байт совпадают с локально проверенной сигнатурой PNG. Это не доказательство доступности заказов или личного кабинета.
- **Doculite.** Точный опубликованный старый вход `doculite.com/home` отвечает 301 на `personal.documentolog.com/home`. В тех же двух сетях завершились GET для целевого HTML и опубликованных CSS и JS. Целевой Personal уже в +128. Никаких утверждений о выполнении JS, входе или подписи.
- **Митворк.** Личный кабинет `eep.mitwork.kz` уже совпадает с `.kz`. Официальная ссылка на руководство поставщика ведёт на отдельный `mitwork-team.atlassian.net`. Два полных 200 со строгим TLS и двумя маркерами содержимого. Это точное исключение только для выделенного tenant, не для родительского домена Atlassian.
- **В наблюдениях.** У `apicom.documentolog.com` три сети подтвердили HTTP 206 для идентичного префикса опубликованного PDF (4 096 байт). Полный GET или короткая содержательная публичная страница из двух сетей не подтверждены. `leeloo.documentolog.com` — ссылка политики необязательного чат-виджета, не подтверждённая обязательная зависимость.

[VPN GET](vpn-evidence.tsv) — 70 наблюдений по пяти прогонам, 58 HTTP-ответов, из них 56 с curl 0 и TLS verify 0 (включая строгие 301/302 и ограниченные 206). [Globalping](globalping-evidence.tsv) — 32 измерения и 96 отдельных строк, в первых двух группах 20 ответов от незапрошенного ASN отложены. Не проверялись IPv6, авторизация, операции API, торговые и платёжные операции. [Хеши архивов](wave-summary.json).

[Предпросмотр DAT](dat-preview.tsv): Light 4 447 → 4 580, Server 4 335 → 4 468, +133/−0 к v11.20. [Все 18 SRS](srs-preview.tsv) декодированы, 17 нероссийских категорий не изменились побайтно. Новых коллизий с BLOCK нет. [Публичные ссылки на версии](publication-guard.tsv) не менялись. Сборка только для исследования, публикация не выполнялась.

Точка продолжения: проверить, есть ли у `apicom.documentolog.com` короткая, явно опубликованная публичная зависимость. Не выполнять вызовы закрытого API и не добавлять `leeloo.documentolog.com` только по ссылке на политику чата. Продолжить поиск у казахстанских EDI/логистических операторов по ссылкам из пользовательских руководств, отдельно от уже покрытых .kz-входов.
