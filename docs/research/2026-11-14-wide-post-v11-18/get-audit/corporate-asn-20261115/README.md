# Корпоративные домены и крупные ASN — 15.11.2026

Сравнение с опубликованными GeoSite Light и Server v11.19. Проверены SHA-256 Light `fea7efa5c855ead11d2e8dd867f41d3b395afddba10013d0613e0c592ea7ca9f` и Server `a4e42e899853f7095b7a0c13f04115c6d9cc851733b4c2448671ee00a682ee25`. Учитывались точные правила, суффиксы, `BLOCK` и остальные категории Light. `operator_reference` в исходной сводке — организационный ориентир, а не origin всех записей. Названия из документации учитываются отдельно от рабочих доменов. HTTPS GET выполнен только для специально перечисленных публичных URL, без входа, без отправки форм и без Globalping.
