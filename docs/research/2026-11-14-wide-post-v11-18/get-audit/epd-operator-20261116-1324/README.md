# Рабочие входы ИС ЭПД и транспортная логистика, 16.11.2026

Старт от [очереди +98](../epd-followup-20261116-1242/candidate-plus98.txt). Итог — [очередь +117 без удалений](candidate-plus117.txt), 19 новых `full:` из этого прохода. [Решения и исходные URL](decisions.tsv), [26 документированных хостов и существующее покрытие](operator-endpoint-coverage.tsv). 22 из 26 уже покрыты обоими DAT v11.20, четыре есть в +98. Это выборка рабочих ссылок, не новый подсчёт полного реестра.

- **ALTLOG** — [официальная ссылка](https://altlog.ru/altlog.online) ведёт на `altlog.online`. Два одинаковых 302 на `/login` и два завершённых 200 на конечной странице проверены отдельно. Авторизация не проверялась.
- **Светофор Логистика** — [соглашение](https://svetofore.com/privacy-page?tab=agreement) прямо перечисляет оба домена платформы. `.ru` уже покрыт. Для `.com` подтверждены публичные главная, соглашение и форма регистрации. Регистрация не выполнялась.
- **CARGO.RUN** — `cargo.run` подтверждён как опубликованный адрес с редиректом к уже покрытым страницам `cargorun.ru`. Проверен одинаковый 301 и целевой 200 из тех же двух сетей. [Официальный сайт](https://cargorun.ru/) публикует отдельный `routes.cargo.run`; на этом имени независимо подтверждены публичная страница и опубликованный CSS. Документацию `cargorun-ru.github.io` оставляем только под действующим `GITHUB` (`domain:github.io`).
- **Veeroute** — 15 точных имён: основной `veeroute.cloud`, две документации и по шесть точных адресов ролей/примеров для двух окружений. Источники — [переход с официального .ru](https://veeroute.ru/), [англоязычный справочник](https://docs.edge7.veeroute.cloud/en/) и [русскоязычный справочник](https://docs.prod7.veeroute.cloud/). Проверены публичные оболочки кабинетов и по одному официальному файлу примеров OpenAPI-клиента, а не операции API. `veeroute.com` вне очереди: 200 с полным переносом лишь в одном исходном измерении, в повторах — таймауты, в том числе после получения заголовков 200. Аналитика и общий суффикс `veeroute.cloud` не добавлены.
- **Транспортные контроли** — `isales.trcont.ru/help`, `epd.tochka.com`, `edo.pkitrans.ru` дважды остановились на строгой проверке цепочки TLS (curl 60, verify 19); это не доказательство блокировки, и покрытие .ru сохранено. Тестовый кабинет, демо и подрядчик `drozd.red` не дали оснований расширять RU. Контакты внесённой в реестр КОМИТА не заменяют доказательство актуального продуктивного входа.

[Архивы и метрики](wave-summary.json): девять групп, 118 наблюдений по 51 уникальному URL, 94 завершённых HTTP-ответа со строгой проверкой TLS. Проверены выходы AS8402, AS12389, AS28840, AS34974, AS42610. Первые две попытки с ошибкой формата TSV исключены из статистики. Каждое включённое имя подтверждено одним и тем же публичным URL хотя бы из двух сетей. Для редиректа дополнительно проверен целевой публичный URL. IPv6, вход, подписание документов и операции API не проверялись. [Наблюдаемые BGP origin](origins-all.jsonl) описывают только IP, увиденные в прогонах, не обосновывают добавление префиксов.

[Все 18 SRS](srs-preview.tsv) прошли обратное декодирование, 17 категорий вне RU совпали побайтно. SRS для Server проверен как локальная проекция, не публикационный актив. Тесты: 4 Light SRS, 13 Server и 16 VPN-адаптера. [Публичные refs](publication-guard.tsv) не менялись. Релиз не запускался, изменения только в исследовательской ветке Geosite-ru-light.
