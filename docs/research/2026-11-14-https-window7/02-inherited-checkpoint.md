# Проверка шести альтернативных путей

Шесть URL из предыдущего журнала получили уникальные ID. Пять ответили HTTP 200 с корректным TLS на всех трёх ASN, но не дошли до достаточного читаемого содержимого в ответе измерительного сервиса. У REVI сессия TLS установлена и SAN совпадает, но HTTP-ответ не получен из всех трёх сетей. Это не подтверждение блокировки. Все шесть оставлены в удержании, +365 / −0 сохраняется.

Начальная квота 79, резерв 19. В журнале нет сырых HTML-ответов, только компактные признаки и ID. Старые неизвестные отправки не повторялись.
