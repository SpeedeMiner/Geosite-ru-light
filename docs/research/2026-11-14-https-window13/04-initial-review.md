# Первая очередь и восстановление

Из 11 URL отправлены все 11, получено 33 наблюдения. Из двух альтернативных страниц из прошлого окна у woodworking.minskexpo.com получен полноценный пресс-релиз выставки, у mf.plastigy.com только усечённый HTML без видимого тела. Подтверждён только точный хост белорусского организатора. Подтверждение организатора также в [плане ЕЭК](https://eec.eaeunion.org/upload/medialibrary/1d2/xrx1xwk030i2vsfc9y22jevrv1tiqqti/Meropriyatiya-2026-god_.pdf).

На rosla.com снимок содержит заголовок и его повтор, не содержимое сайта. У skifltd.com снимок остановился на шапке «Москва / Отдел оптовых региональных продаж», FAQ не виден. Эти два автомата «https_candidate» вручную не одобрены. Для WWW IDN «Венские стулья» наблюдался 301 на корневое IDN имя, покрытие не расширено на WWW.

Старый ID best-dreams.com выдал результат без повторной отправки. Две точки видят заглушку хостинга «Домен не привязан к хостингу», третья не вернула HTTP-ответ. Кандидат оставлен вне RU, это не подтверждение блокировки.
