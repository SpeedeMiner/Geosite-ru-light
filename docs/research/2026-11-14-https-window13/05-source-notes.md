# Новые источники и текущие ограничения

- [Транспорт России 2026](https://2026.transweek.digital/ru/expo/exhibitors/) — выборка карточек транспорта, профильных СМИ, образования и инфраструктуры. Домены берутся из поля сайта самой карточки. Если поисковый фрагмент не содержит Контакты, помечается как неполный, а не как отсутствие сайта.
- [БелПромФорум-2026](https://belpromforum.by/participants-list) — отдельные карточки, в которых страна и сайт указаны явно. Соцсети не считаются самостоятельными сайтами экспонента.
- [Белагро — экспозиция российских компаний](https://belagro-russia.ru/) — 21 карточка; отсутствие опубликованной ссылки не заменяется автоматически доменом электронной почты.
- [Продэкспо-2026](https://icatalog.expocentr.ru/ru/exhibitions/870c9c18-e84b-11ef-80ce-a0d3c1fab97f/countries/Russia) — равномерная выборка по алфавитным страницам, плюс отдельные каталоги [Беларуси](https://icatalog.expocentr.ru/ru/exhibitions/870c9c18-e84b-11ef-80ce-a0d3c1fab97f/countries/Republic%20of%20Belarus) и [Казахстана](https://icatalog.expocentr.ru/ru/exhibitions/870c9c18-e84b-11ef-80ce-a0d3c1fab97f/countries/Republic%20of%20Kazakhstan?page=1). Только поле «Сайт» карточки и точное соответствие страны.
- [AstanaBuild](https://reg.iteca.kz/list/exponent/auth.aspx?ExhCode=AstanaBuild+2026) — полный индекс Iteca и подробные карточки RU/BY/KZ; поля «веб» и город сравниваются с идентификатором экспонента. Записи без ссылки можно использовать для отдельной проверки официального сайта по названию.
- [TransLogistica Kazakhstan 2026](https://reg.iteca.kz/list/exponent/auth.aspx?ExhCode=TransKazakhstan+2026) — 192 карточки в полученном полном HTML-виде индекса, 127 с меткой RU/BY/KZ. 63 подробные карточки в выборке: все 30 RU/BY и каждая третья из 97 KZ. Это число карточек доступного онлайн-индекса, не объявленное организатором число участников мероприятия.
