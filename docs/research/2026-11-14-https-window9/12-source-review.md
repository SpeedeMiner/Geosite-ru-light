## Решения по спорным именам

- `globalinklogistics.com` указан в госзакупках KZ, но три HTTPS-проверки показывают `UNABLE_TO_VERIFY_LEAF_SIGNATURE`. То же у `vonadi.com` при подтверждённом операторе в Минске. Оба удержаны, результат не доказывает блокировку.
- `allglobus.com` и WWW — HTTP 503 со страницей SpaceWeb в трёх сетях. Для `www.acex.net` — 301 на apex, но отдельное полное подтверждение apex пока не получено. МедЭлемент WWW также лишь перенаправляет на уже покрытый apex.
- У `www.aigp.asia` три разных пути дают убедительную идентификацию из меню, но предоставленные измерением фрагменты не содержат основного текста запрошенной страницы. Не используем для добавления. Apex перенаправляет на WWW.
- У `necoline.net` и `acex.net` последняя волна показала только навигацию или шапку при HTTP 200. Каталог на `exhibitors-itegroup.exhibitoronlinemanual.com` также удержан: фрагмент только до списка стран, оператор всего точного имени отдельно не подтверждён.
- Для `belagrobel.com` первоначальную привязку по витрине уточняет [политика](https://belagrobel.com/processing-of-personal-data.pdf) — ООО «Белагро Бел». Два пути вернули усечённый ответ без видимого текста, правила нет.
- География филиала, названия выставки, почтовый адрес и результаты поискового индекса по отдельности не меняют маршрутизацию.
