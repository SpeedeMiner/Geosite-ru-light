# Контрольная точка 2 · верификация источников без новых замеров Globalping

Из 284 входных имён проверены 234 уникальных URL, ранее указанных как источники обнаружения. 215 страниц дали HTTP 200, для 209 имён найдено точное вхождение в ссылку, а не только упоминание подстроки. Это инвентаризация происхождения ссылок, не подтверждение страны оператора и не новая проверка доступности самих сервисов из РФ. Код 000 относится к запросу из рабочего окружения. Для реестров и каталогов, которые не отдал этот маршрут, отдельно применялись доступные индексированные копии.

Проверены дополнительные случаи с юридическими данными глобальных сайтов. Из 13 разобранных имён 11 не подходят по оператору, два оставлены спорными. Например, Andersen на точном домене указывает польского контроллера, а LeverX использует один домен для операторов разных стран, в том числе KZ и US. Общие сайты зарубежных производителей не попадают в RU лишь потому, что их показывают на выставке в России.

Выделены 23 приоритетных точных пути для новых замеров TLS. Для нескольких образовательных сервисов найдены первичные документы, например оферта iSmart, лицензия SF Education, реквизиты «Битроникс» и подтверждение российского оператора Online Test Pad. Ничто из этой очереди не продвигается по одному HTTP 200 или записи каталога. Кандидат остаётся **+306 / −0**.

- `02-discovery-evidence-*.jsonl` — URL источника, статус, точные ссылки и краткий контекст. Это данные происхождения, не решение.
- `02-operator-decisions.tsv` — решения по зарубежным и спорным операторам.
- `02-next-exact-paths.tsv` — приоритетная очередь, включая операторские документы там, где они найдены.

Проверка через `/v1/limits` показала остаток одного запроса-пробы и сброс позже окна прохода. Не отправлять повторно трёхсетевые замеры до восстановления квоты. Следующий этап: провести ручную юридическую сверку по приоритетным отраслям, расширить очередь точных путей и сохранить её отдельным коммитом.
