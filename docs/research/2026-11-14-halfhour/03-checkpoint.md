# Контрольная точка 3 · VOKA закрыта первичным документом

В прошлой очереди два имени VOKA были отложены из-за отсутствия договора оператора. Найден [публичный договор на сайте поддержки А1](https://support.a1.by/ofitsialnaya-informatsiya/dogovor/dogovor-ob-okazanii-uslugi-voka/). В нём указаны белорусское унитарное предприятие «А1», лицензия оператора и точный адрес `www.voka.tv`.

Из сохранённых в журнале замеров восстановлена вся HTTPS-цепочка `www.voka.tv/ → voka.tv/ → voka.tv/ru-RU`. На каждом шаге SAN соответствует точному имени и сертификат доверен из AS3216, AS12389 и AS207957. Цель дважды дала рабочую страницу с HTTP 200. Это проверка публичной витрины, не доступности каталога или воспроизведения видео в России.

Приняты `full:voka.tv` и `full:www.voka.tv`. Вся дельта **+308 / −0** относительно v11.17. Light 4154 RU, Server 4042 RU. Остальные категории Light, включая 44 BLOCK, побайтно неизменны. Server по-прежнему содержит только RU. Штатные сборки и независимое воспроизведение совпали побайтно.

- Light SHA-256 `fa0eee00bec39c78dd781b6ae52a678af80eb99fbcb5f91bcc0203c432870cae`
- Server SHA-256 `af7720433cf5bee6cba0e226ec38e4f9f2c6eaf79f5d1efe7ca7e66ee4548c0e`

Данные в `03-voka-evidence.jsonl`. `www.medelement.com` остаётся отложен до подтверждения именно корневой цели редиректа.
