# Альтернативные пути B

Начальная квота 175. Все 15 путей получили ID и результаты из трёх требуемых ASN. Принято одно точное имя, 12 удержаны из-за содержимого, одно по редиректу, одно после ручного ревью.

- `www.eltis.com` принят по `/en/`. Кодировка ответа всё ещё Windows-1251, и часть русского меню повреждена. Однако три ответа содержат читаемые английские абзацы о самой компании и продукции. Это не попытка восстановить потерянные байты. [Английская страница](https://www.eltis.com/en/), [контакты](https://www.eltis.com/contacts/) и [политика оператора](https://www.eltis.com/upload/privacy-policy.pdf) привязаны к точному www.
- `www.asi-log.com` остаётся на удержании. Во всех трёх ответах видимый текст практически полностью состоит из баннера о cookie. Бренд в метаданных без содержимого страницы не является достаточным основанием.
- `prostorlab.com` вернул одинаковый HTTP 301 на `https://prostorlab.com/prostor-platforma2/` с трёх точек. Старый путь не даёт допуска, конечный URL проверить отдельным GET.

Всего в трёх партиях 40 путей с ID, по три пробы на путь. Четыре новых допуска, 33 удержаны по содержимому, два по результату ручного ревью, один по редиректу. Суммарный кандидат +361 / −0.
