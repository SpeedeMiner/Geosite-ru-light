# Финальная сверка доказательств для v11.18

Из исследовательского +407 исключён один ранее неопубликованный кандидат wefiftytwo.com. Он унаследовался из списка +248, хотя журнал трижды показал HTTP 200 и доверенный TLS без видимого основного содержимого; статус был «отложено: не хватает сведений». Результат перечитан по прежнему ID. Публичная связь студии с историческим доменом известна, но не закрывает отсутствие основного содержимого в измерении.

Итоговый набор +406 относительно v11.17 состоит из подтверждённых точных имён. Он отличается от +406 прошлого окна: включён отдельно проверенный doshirak.com, а wefiftytwo.com не выпускается. Из опубликованного v11.17 ничего не удалено.
