# Изолированная репетиция нумерованного релиза

Проверен штатный `tools/verify_numbered_geosite_recovery.py` на копии Light `3f55548` с кандидатом +342. Тег `v11.18` использовался как тестовый аргумент и не создавался. В рабочую копию подставлены только манифест кандидата, его список `full:` и локальная запись для проверенного отката v11.17. Исследовательские и рабочие refs не менялись для этой репетиции.

Штатный скрипт восстановил закреплённые входы из ZIP без сети, собрал DAT, сверил SHA-256 и размер всех пяти основных файлов кандидата и подготовил все пять файлов v11.17 для отката. Пины отката сверены с digest и размером из метаданных опубликованного GitHub Release. В текущем реестре main последняя запись для отката v11.16. Перед реальным выпуском с baseline v11.17 эту запись придётся добавить отдельным изменением, затем повторно сформировать квитанцию на фактическом коммите.

С тем же закреплённым sing-box 1.13.12 отдельно получен идентичный манифест всех 18 SRS. Это важно, потому что штатная квитанция восстановления покрывает только пять основных файлов. `13-rehearsal-receipt.json` — запись репетиции, не разрешение на публикацию.
