# Готовые партии на следующий сброс

`make-next-wave.py` сверяет разбиение всех 159 имён, точные URL, оператора, уникальность хостов и отсутствие повторов завершённых URL. Он только формирует TSV, не отправляет измерения.

| Файл | Имена | Пробы |
|---|---:|---:|
| 08-wave-a.tsv | 18 | 54 |
| 08-wave-b.tsv | 24 | 72 |
| 08-wave-c.tsv | 24 | 72 |
| 08-wave-d.tsv | 11 | 33 |
| Итого | 77 | 231 |
| Остаток из 250 | — | 19 |

В первые 77 входят все 56 готовых имён без замера, 20 альтернативных путей для ранее измеренных и отдельно `lab50.net` из другой отложенной группы. В `08-wave-later.tsv` ещё 15 альтернативных путей. Не запускать их все в том же часе. Из 81 имени без замера 25 остаются в журнале с причиной, а не в пачке на автоматический запуск.

Каждая партия запускается отдельно после проверки текущей квоты, с резервом на остальную работу. Проверка HTTP и содержимого не может доказать юридическую привязку, а справочный ответ сайта не заменяет три AS. Для `bigmachine.pro` разрешён повтор URL, потому что оба предыдущих ответа не выдали ID. Для уже принятых имён автоматических повторов нет.
