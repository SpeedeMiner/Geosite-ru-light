# Пять целевых перепроверок

После A–D API показал 34 из 250. План A–D фактически списал 216 проб, пять заявок не получили ID. В эту же квоту помещаются пять точных GET по три ASN, остаются 19 в резерве. Предел 231 в текущем окне не увеличен. Повторы с неизвестным статусом POST не отправляются.

У Капитана и Amata тестируется ровно то назначение, которое все три ASN указали в 301, но отдельным GET без переноса прежнего результата. У ProgKids проверяются публичные контакты, у Optimelle — раздел о компании, у Эквирона — найденная политика точного apex. Эти пути не повторяют завершённые измерения и не включены в A–D.
