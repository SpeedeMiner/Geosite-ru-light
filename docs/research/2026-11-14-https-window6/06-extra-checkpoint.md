# Вторая отраслевая партия

Два обращения к API квоты завершились без HTTP-ответа до создания измерений. Это подтверждено отсутствием каталога отправки и порядком в runner. Повторили только предварительную проверку квоты, затем запустили одну партию из четырёх URL. Все четыре получили ID и ответы трёх заданных ASN.

Приняты три точных правила:

- `3d-made.com` — во всех трёх ответах доступны воронежские контакты и текст политики. Реквизиты оператора совпадают с подтверждённым АО.
- `winnum.io` — во всех ответах есть тематическая навигация по продуктам WINNUM и содержимое брендированной страницы. Собственные контакты и новость связывают витрину с ООО «СИГНУМ».
- `internal.winnum.io` — получен полноценный фрагмент политики, где СИГНУМ прямо назван администратором. Правило строго для этого имени, без расширения на другие хосты WINNUM.

`planetarium.one` вернул HTTP 200 с доверенным TLS, но усечён до достаточного текста. Удержан. Суммарный кандидат +365 / −0.
